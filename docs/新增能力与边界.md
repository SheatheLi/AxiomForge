# 异步资源生命周期轨迹审查

`axiomforge.resource_lifecycle`增加资源借用、关闭开始、取消、释放与生命周期终点的协议审查。通过不同结局`RELEASED`、`INDETERMINATE`、`OPEN_AT_TERMINAL`和`PROTOCOL_VIOLATION`区分确认、信息缺失与冲突轨迹，避免把一次记录的Close调用误判为外部资源真正释放。

运行：`python -m axiomforge.resource_lifecycle examples/resource_trace.json`（需先安装`pip install -e .`）。

**限制**：输入事件由外部仪表记录，分析器不会神奇知道真实Socket或连接池内部状态；resource_id在该协议中必须唯一标识一次借用生命周期，不是可永久复用的物理连接ID。
